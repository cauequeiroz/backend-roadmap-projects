# GitHub Activity CLI

A simple command-line application built with Java to fetch and display a GitHub user's recent activity.

The application uses the GitHub API to retrieve public events, such as commits, issues, and starred repositories, and displays them in the terminal.

**Project:** [GitHub User Activity — roadmap.sh](https://roadmap.sh/projects/github-user-activity)

## Usage

### Fetch user activity

```bash
github-activity kamranahmedse
```

### Example output

```text
- Pushed a commit to kamranahmedse/developer-roadmap
- Opened a new issue in kamranahmedse/developer-roadmap
- Starred kamranahmedse/developer-roadmap
```
